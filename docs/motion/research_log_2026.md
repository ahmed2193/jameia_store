# Hero 2026 motion — Phase 1 research log

Date: 2026-09-28

## Method

1. Ten parallel researchers (R01-R10) each searched the web for a slice of the scope (Android/Material, Apple/iOS, Flutter, MENA delivery apps, global delivery/commerce apps, AI assistants, accessibility + haptics, UX feedback patterns, UX structural patterns, mobile performance), opened every source they cite with WebFetch (raw GitHub source where a page was JS-rendered), and wrote a findings table + source table + gaps list per topic file.
2. **R01 (Android/Material) and R02 (Apple/iOS)** then went through a second, adversarial pass: every Evidence URL and every Source URL was re-fetched and checked claim-by-claim against what the page actually says. Result: **0 rows dropped, 12 rows narrowed** ("corrected: ..." in the finding text) across the two files, 3 source-row corrections. Nothing survived on trust; everything left is either verbatim-confirmed or explicitly marked `[INFERENCE]` as the researcher's own reasoning, not a claim from the source.
3. **R03-R10** got a lighter second pass: every cited URL was mechanically checked for liveness only (not re-read claim-by-claim). Result, from `research/liveness_R03_R10.json`: **367/367 URLs live**. The handful of HTTP 403s are bot-blocking by Medium, the App Store and LottieFiles (the page exists, the fetcher was refused), and the three 404s are Apple URLs the checker cut at a stray parenthesis — the real URLs resolve. So R03-R10's *URLs* are confirmed to exist; their *claims* are first-pass only (each researcher read the page themselves once, but no second researcher re-verified the quote).
4. Every research file hit the **same shared 200-call session WebSearch budget** at some point and finished on WebFetch of already-known URLs. Each file's own Gaps section names the exact queries that were never run.
5. This log deduplicates all ten files' source tables into one table below, and folds all 332 findings into `research/digest.md`, grouped by the 15 topics in the task brief.

- **Sources, deduplicated by URL: 395** (raw source rows across the ten files before dedup: 507; 112 rows were the same URL cited by more than one researcher — mostly the M3 Expressive spring tokens, the Android/Apple predictive-back specs, the WCAG success criteria, the Apple HIG Motion/Accessibility/Playing-haptics pages, the Flutter reduced-motion API docs, and `rive.app/blog/rive-as-a-lottie-alternative`, each pulled in by 2-5 different researchers).

The remaining **28 sources (7%) are explicitly pre-2025** and are kept only because each is still the standing reference a 2025-26 page itself points back to.
