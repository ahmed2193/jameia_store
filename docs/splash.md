# Hero — logo, splash and app icon

The app is called **Hero**. The brand idea is *the everyday grocery hero*: a
shopping bag wearing a cape, with the "h" of the name on its front like a
hero's chest emblem. It flies your groceries to you.

- **Colours**: Hero green `#22C55E` (`AppColors.primary`) behind a white bag
  with a yellow cape (`accent4` `#FFEA52`). On white: a green bag, an amber cape
  (`proAmber` `#FBBF24`) and the name in `primaryDark` `#16A34A`.
- **Kept apart from Delivery Hero** (a large regional delivery group whose
  logo is a red ascending star, and which once used a caped superhero): no
  red, no star, no caped person, no black italic type.

## The mark

`HeroMark` (`lib/src/core/design/hero_mark.dart`) is built from plain shapes in
a 100-unit square:

| Part | Shape |
|---|---|
| Bag | a rounded trapezoid, slightly wider at the bottom |
| Handle | a half-ellipse arch standing on the bag |
| Emblem | the "h" of Fredoka Bold, cut out of the bag (it shows what is behind) |
| Cape | tied behind the bag's top-left corner. It flows back 36 units and flares to 40 units at the tail. A travelling wave (1.2 waves) ripples it, and the tail ends in 3 scalloped points. At rest the wave is 3 units at phase 0.6. |
| Gap | 1.8 units cut between the cape and the bag, so the bag stands in front |
| Pose | the whole mark tips back 8° about the bag's middle, nose up, as if climbing |

One painter draws it everywhere: `HeroMarkPainting`. The splash, the Home tab
icon (`HeroMarkIcon`), the launch image and every app icon all use it.
`HeroMarkPose` moves it:
- squash on its bottom edge and lift;
- extra lean;
- the cape's wave and phase;
- how much of the cape's darker underside shows.

`HeroMarkPainting.matrixFor` gives the same transform, so code can know where
the bag is on screen.

`HeroMarkColors` has three versions:
- `onBrand`: white bag, yellow cape.
- `onWhite`: green bag, amber cape.
- `mono`: one colour, used for Android themed icons and the resting Home tab.

## The name

- **"hero"**: Fredoka Bold, lowercase, tracking −10 units.
- **"هيرو"**: Baloo Bhaijaan 2 ExtraBold, the rounded Arabic companion of the
  Baloo family, drawn 1.2× larger so the two read the same size.
- Both are vector outlines in `HeroGlyphs`, generated by
  `tool/splash/build_brand_glyphs.js` (opentype.js does the Arabic shaping). No
  font is shipped. Both fonts are SIL OFL 1.1.
- **Lockup**: the bag (not its cape) stands centred over the name. The mark is
  2× the name's height, 0.3× above it.
- **Tagline** (`splash.tagline`, live text): "Your everyday grocery hero" /
  "بطلك اليومي لكل مشترياتك".

Where the name shows:
- The launcher label: Android `android:label` and iOS
  `CFBundleDisplayName` / `CFBundleName` are "Hero" in every language.
- The web title and manifest.
- `app_name` and every brand string in `assets/i18n` ("Hero Pro",
  "Hero Assistant", …). In Arabic the verbs agree with a masculine هيرو.

The code carries the name too: the Dart package is `hero_mart`, the classes
are `Hero*` (`HeroAssets`, `HeroTransitionPage`, …) and the API skills are
`.claude/skills/hero-api-*`.

Kept on purpose, because renaming them breaks something outside the code:
- the application id / bundle id `com.jameiamart.app` (store and signing
  identity);
- the backend hosts (`api.jm3eia.store`, `media.jm3eia.com`) and their docs;
- the saved-data keys `jameia.addressbook.v1`, `jameia.orders.v1`,
  `jameia.search.recents.v1` and `jameia.home.popup_shown.*`: phones that
  already have the app keep their data under them;
- the social handles on the About page, until Hero's own accounts exist;
- the repo folder `keeta_clone`.

Texts the server sends (plan names, assistant replies) come as the server
writes them.

## Splash flow

1. **Native splash**: Android 12+ SplashScreen API, Android ≤11 launch theme,
   iOS LaunchScreen.storyboard. It shows green `#22C55E` with the mark centred
   (`assets/splash/splash_mark.png`, 1152² read as 4× → a 288 dp/pt box). The
   mark's farthest point (reach × `nativeUnit` 1.7 = 88 dp) stays inside the
   96 dp circle Android 12 keeps.
2. **Flutter splash** (`features/splash`): its first frame repeats the native
   one exactly, drawn by the same painter at the same size and place. It holds
   still until that frame is really on screen: first frame rasterized, then
   `AppMotion.splashHandOffHold` (600 ms fallback). Then the intro plays.
   `MainActivity` removes the Android 12 system splash at once; its default
   exit dimmed the logo.
3. **Hand-off**: `context.go(Routes.shell, extra: ShellEntrance.splash)`. The
   shell fades in (`HeroFadeThroughPage`).

## Versions

Pick one at build time with `--dart-define=SPLASH_VARIANT=<name>`
(`SplashVariant`, default `wordmark`):

| Name | What plays | Length |
|---|---|---|
| `wordmark` | The hero flight: straight from the launch frame the bag takes off and delivers the name. White on green. | 2.0 s |
| `basket` | The grocery run: a bottle, an orange and some greens drop into the bag, which dips and flicks its cape under each. Then the full bag takes off. The groceries stay peeking out of the bag. | 2.55 s |
| `burst` | The bag breathes in, then a white disc bursts out of it. The screen becomes the full-colour logo on white (the home screen's colour) while the bag flies and delivers. | 2.25 s |

## The hero flight (the shared finish, `SplashAssembly`)

| ms (after its start) | What happens |
|---|---|
| 0–130 | Crouch: the bag flattens onto its bottom edge. |
| 130 | Take-off: a flat dust ring where it stood, and a stretch as it leaves the ground. |
| 130–650 | Flight: it swoops 36 dp forward and 64 dp up, then glides into the lockup. It tips further back, its cape whips (bigger wave, faster travel, its amber underside twisting into view) and slanted streaks fade behind it. |
| 650 | Arrival: a ring in the air and a pulse of the glow behind it. |
| 690 → | Delivery: every 80 ms (Arabic: 150 ms, two joined runs) the bag throws the next piece of the name. Each piece pops out of the opening, flies a ballistic arc into its place (growing, turning upright, hidden while it passes behind the bag) and squashes as it lands. Each throw bobs the bag and flicks its cape. |
| last landing | Confetti from the name, a light sweep across the whole lockup, the tagline fades in. |
| to the end | The bag floats (1.6 units, 1.7 s a bob), its cape rippling. |

Under all of it:
- A living colour layer: a soft glow that follows the bag, plus three slow
  blobs. It fades in from the flat launch frame.
- **Touch**: a ring where the finger lands and the glow leans after it.
  Tapping the bag makes it hop and flick its cape, with a light haptic. Touch
  never changes how long the intro plays.
- **Reduced motion**: the finished lockup at once, no touch effects, then the
  app after `AppMotion.splashReducedHold`.

## How it is built

- The whole scene is one `CustomPaint` (`SplashScenePainter`) driven by one
  `AnimationController`, so it repaints without rebuilding widgets.
  - A choreography turns the clock into a `SplashFrame`.
  - `SplashScenePainting` draws it, back to front: background → glow → rings →
    streaks → [flying name → mark (with groceries in the bag)] → confetti.
  - While the light sweeps, the name and the mark share one layer, so the band
    lights only them.
- The name the bag delivers follows the app language (`SplashWordmark`). The
  tagline is translated live text. The logo itself is never mirrored.
- The cape is computed per frame from its wave and phase (21 points, cubic
  curves). The gap is a clip; the emblem hole and the resting cape are cached.

## Regenerating

```sh
# the letters (see the script header for the two font downloads)
node tool/splash/build_brand_glyphs.js fredoka-700.ttf baloo-bhaijaan-2-800.ttf
# the launch image, then the Android / iOS launch screens
flutter test tool/splash/render_native_splash_test.dart
dart run flutter_native_splash:create
# the app icons + the in-app logo, then the Android / iOS / web icons
flutter test tool/splash/render_app_icons_test.dart
dart run flutter_launcher_icons
# flutter_launcher_icons 0.14.4 bug: it rewrites this pbxproj setting to AppIcon; put it back
sed -i 's|ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = AppIcon;|ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = YES;|' ios/Runner.xcodeproj/project.pbxproj
```

## Traps

- `flutter_native_splash` keeps style items it did not write. So
  `android:windowLightStatusBar=false` in `values-v31` / `values-night-v31`
  (white status bar icons on green) survives a regenerate.
- iOS caches launch screens: delete the app (or restart the simulator) to see a
  change.
- `flutter_launcher_icons` never deletes old sizes. Remove PNGs in
  `AppIcon.appiconset` that `Contents.json` no longer lists.
- One `pump(d)` is one frame in widget tests: a ticker's first tick reports
  elapsed 0, so tests prime it with a `pump()`.
